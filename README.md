# Object Evolution

Turn one photograph of an object into a **continuous metamorphosis shot** — metal ring → living plant → organic flesh → mechanical organism — in a single unbroken take, with synchronized sound.

Entry for the [Comfy Open Source Higgsfield challenge](https://comfy.org/open-source-higgsfield/). Built on ComfyUI + Comfy Cloud with LTX-2.5.

## How it works

The stage images are never the output. They are pinned to specific frames of **one** generation as guides; everything between them is generated by the model.

```
photo → structural anchors (depth + edges)
      → N stage images (ControlNet-locked to the anchors)
      → guides pinned at frames 0, 1/3, 2/3, end
      → one LTX-2.5 pass (video + audio)
      → continuous morph → loop / 9:16 / 16:9 export
```

## Stack

| Layer | Choice |
| --- | --- |
| Frontend | React + Vite + TypeScript, Tailwind, dnd-kit |
| Backend | Python 3.13 + FastAPI, one in-process asyncio worker |
| Comfy | Comfy Cloud — `comfy-sdk` + the documented HTTP API |
| Video model | LTX-2.5 (subject to the quality matrix) |
| Storage | SQLite + local disk |
| Processing | ffmpeg (exports, thumbnails) |
| Serving | Caddy + systemd (no containers) |

## Layout

```
api/         FastAPI service + job worker
web/         React app (Vite build served by Caddy)
workflows/   API-format ComfyUI workflow JSONs — the pipeline as data
docs/        stack notes and decisions
```

## Quickstart

```bash
# api
cd api
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
COMFY_API_KEY=comfyui-... uvicorn app.main:app --port 8010

# web
cd web
npm install
npm run dev
```

The API key is read from `COMFY_API_KEY`, or from `COMFY_API_KEY_FILE` (default `/root/.comfy/cloud_key` on our build box). It is never committed.
